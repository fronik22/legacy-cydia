Mak Legacy Cydia repository

Packages for jailbroken 32-bit and early 64-bit iOS devices. Add this source in Cydia:

https://fronik22.github.io/legacy-cydia/

Every package states its tested range. iOS 7 support is only claimed after an install and runtime check on a real device. Packages that are not ready are marked untested; incompatible firmware dependencies prevent installation rather than guaranteeing that Cydia hides an entry.
