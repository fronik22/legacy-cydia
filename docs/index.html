Mak Legacy Cydia repository

Packages for jailbroken 32-bit and early 64-bit iOS devices. Add this source in Cydia:

https://fronik22.github.io/legacy-cydia/

Every package states its tested range. iOS 7 support is only claimed after an install and runtime check on a real device. Packages that are not ready are marked untested; legacy-only packages stay hidden from iOS 7 by their firmware dependency.
