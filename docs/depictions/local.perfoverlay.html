Performance Overlay

FPS / CPU / RAM / GPU HUD for iOS 4.3–9

FPS / CPU / RAM / GPU HUD for iOS 4-9.

Shows live system counters in a small non-interactive overlay. Includes an NCSettings toggle on iOS 5/6.

0.1.12 restores selected refresh; removes rejected idle slowdown. AGX point-stat reads consume counters, so earlier30%means did not establish wall-time load. Independent same1HzHUD GPU performance-state residency is~0.50%. New verifiediOS7 arm64/A7 backend shows GPU on (non-OFF time), not shader occupancy; other platforms show qualified GPUdrv snapshots. Counter delta/clock/overflow guards, UID501/nativeUI tests pass. No Metal rewrite or rootdaemon.
