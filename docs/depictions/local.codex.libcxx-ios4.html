Legacy C++ Runtime (iOS 4)

Shared libc++/libc++abi for armv7 iOS 4.3

Shared LLVM libc++ and libc++abi for armv7 iOS 4.3.x.

Maintains legacy libstdc++ and installs no injection tweak.

Installs the missing shared C++ runtime on iOS 4.3. iOS 5 and later already provide their own runtime, so installation is refused there. This is intentionally not an iOS 7 replacement.
