LocalSend Photos Without Location (iOS 4)

LocalSend-specific old Photos permission gate adapter

Allows native AssetsLibrary access in LocalSend on iOS 4.3.3 without enabling Location Services.

Scoped to com.unlocalsend.ios6 on build 8J2. Grants the app read access to Photos, including location metadata.

Exact iOS 4.3.3 / LocalSend gate adapter; no GPS requests or global location permission change. iOS 6/7 use their native photo permissions and must not receive this hook.
