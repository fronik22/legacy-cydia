Legacy 1080p60 Timing Fix

Guarded H.264 decode-hint fix for iPad 2 / iOS 4.3.3

Corrects the iOS 4.3.3 real-time decode hint for iPad 2 1080p60 H.264.

Preserves video frames, timestamps, audio, asynchronous and temporal decoding.

Exact iPad 2 / 8J2 mediaserverd timing workaround. It is not applied to iOS 7: that decoder path has not demonstrated the same regression. Other media and timestamps are preserved.
