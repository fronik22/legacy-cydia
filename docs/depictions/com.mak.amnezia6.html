Lightweight AmneziaWG client for iOS 4-7

A small native AmneziaWG client: a root daemon owns the UTUN device, routing, DNS and the WireGuard/AmneziaWG 3.1 protocol, and a UIKit app controls it over a Unix socket.

Supports header protection, junk packets, I1-I5 signatures, S1-S4 and H1-H4. Requires a jailbroken device with root access.

1.3.3 fixes current AWG3.1 keepalive ranges and timer consumers, ordered IPv4 DNS lists and bundle DNS placeholders. Native iOS7 QR scanning and sticky completion errors replace the misleading 1/2 loop. User confirmed the same physical animated QR opens the profile editor; authenticated traffic was observed after user connection. Native generated multipart import, timer/authentication regressions and package tests pass. IPv6, exhaustive protocol conformance and older-device optical testing remain unclaimed.
