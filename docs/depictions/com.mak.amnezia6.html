Lightweight AmneziaWG client for iOS 4-7

A small native AmneziaWG client: a root daemon owns the UTUN device, routing, DNS and the WireGuard/AmneziaWG 3.1 protocol, and a UIKit app controls it over a Unix socket.

Supports header protection, junk packets, I1-I5 signatures, S1-S4 and H1-H4. Requires a jailbroken device with root access.

1.3.4 imports official description/hostName automatically through QR, URL and file paths; preserves existing manual names and profiles. Fixes white-on-white iOS7 status bar. Keepalive/timer follow-up removes invented omitted-field keepalives, confirms new keys immediately and renews expired/idle sessions on traffic with bounded staging and monotonic deadlines. Exact host/native/runtime verification is recorded in project receipts; IPv6 and exhaustive AWG conformance remain outside the supported scope.
