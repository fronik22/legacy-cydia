Native iPad layout and suspension fix for Veteris 4

Native iPad layout and suspension crash fix for Veteris 4.

Removes iPhone compatibility sizing, fixes storyboard selection, and adapts home and application-list layouts. Fixes SGX shader-cache suspension kills so Veteris's existing background download support can work normally.

iOS 6 verified. 1.2.0 adds an iOS 7 shader-cache guard and allows iOS 7, but the app has not been run on iOS 7 yet.
