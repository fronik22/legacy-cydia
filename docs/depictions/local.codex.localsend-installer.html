LocalSend (IPA Installer)

Install the adapted LocalSend 5.7.4340 app

Install the adapted LocalSend application using appinst.

Preserves existing IPA containers and user data on upgrade. Cydia removal leaves the installed app and its data intact. Requires Karen's official repository: https://cydia.akemi.ai/.

This package installs the IPA; it is not the app itself. Package, maintainer-script, IPA and armv7 iOS 7 runtime audits pass, but install, launch, photo selection and transfer were not run: the test iPad lacks ai.akemi.appinst / AppSync Unified and cydia.akemi.ai was unreachable. Requires Karen's official source.
