Legacy Device Access

One-shot SpringBoard lock/unlock helper

Explicit root-operated no-passcode screen access for device tests.

Tested on iOS 4.3.3 and 6.1.3. No daemon or boot auto-unlock.

The helper refuses any OS other than 4.3.3 and 6.1.3 on purpose. It is a diagnostic tool, not an iOS 7 package.
