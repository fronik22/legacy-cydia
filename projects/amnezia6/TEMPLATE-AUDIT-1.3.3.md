## Transformation boundary

Client creation resolves address, private/public/PSK keys, endpoint/port,
JUNK_PACKET_*, INIT/RESPONSE/COOKIE_REPLY/TRANSPORT_PACKET_JUNK_SIZE,
INIT/RESPONSE/UNDERLOAD/TRANSPORT_PACKET_MAGIC_HEADER, SPECIAL_JUNK_1–5,
HEADER_PROTECTION_KEY, CONTENT_PADDING_ADDITION, REKEY_AFTER_TIME,
REKEY_TIMEOUT, REJECT_AFTER_TIME, KEEPALIVE_TIMEOUT, MAX_HANDSHAKE_ATTEMPTS,
RANDOM_TRAILERS, DISABLE_COOKIES and PERSISTENT_KEEPALIVE before last_config
is exported. Empty optional generated lines are removed upstream.

Only PRIMARY_DNS/SECONDARY_DNS remain late client substitutions, supplied by
root dns1/dns2. Amnezia6 expands those exact tokens with strict IPv4 metadata;
all other remaining value tokens fail preflight together, even if an earlier
field is invalid. Comments containing `$` are ignored. No server key, address,
resolver or numeric obfuscation default is invented to complete a raw template.
WG default client keepalive is25; AWG3.1 exports explicitly supply25-35.
Mobile MTU default1280 matches this client.

## Every current native field

| Fields | Validation and consumer |
|---|---|
| Address, DNS, MTU | IPv4 tunnel address, complete ordered IPv4 resolver list, bounded MTU; route/interface/DNS service |
| PrivateKey, PublicKey, PresharedKey |32-byte Base64 keys; handshake/transport crypto |
| Jc, Jmin, Jmax | Bounded junk count/size; outgoing obfuscation |
| S1–S4 | Bounded packet prefixes; handshake/response/cookie/transport parsing |
| H1–H4 | Nonoverlapping integer/range types; packet encoding/identification |
| I1–I5 | `<b 0xHEX>`, `<t>`, `<r N>`, `<rd N>`, `<rc N>`; syntax/expanded-size validated before connection; empty optional values emit no packet |
| HeaderProtectionKey |32-byte key plus minimum prefixes; packet header protection |
| ContentPaddingAddition, RandomTrailers | Padding range/toggle; authenticated transport and padded empty keepalive receive |
| RekeyAfterTime, RekeyTimeout, RejectAfterTime | Range-based key renewal/retry/expiry |
| KeepaliveTimeout | Random delayed reply to nonempty authenticated RX; also unanswered-data retry using its upper bound + randomized RekeyTimeout |
| MaxHandshakeAttempts | One sampled limit per handshake round; retry exhaustion/backoff |
| DisableCookies | Responder-only cookie-generation policy upstream; initiator has no corresponding server behavior. Remote cookie challenges remain authenticated/handled |
| Endpoint, AllowedIPs | IPv4/hostname endpoint; IPv4 full-tunnel route policy, existing dual-default syntax accepted |
| PersistentKeepalive | off/0/scalar/range≤65535; random deadline reset only by authenticated TX/RX |
