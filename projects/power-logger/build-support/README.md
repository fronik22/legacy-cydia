The owned iOS9.3 SDK omits arm64 memcpy/strcmp reexport declarations. ios7-system-symbols.tbd supplies only those standard libSystem.B C ABI declarations, not an implementation or an Apple SDK. It prevents executables from using unrestricted dynamic_lookup. Native arm64 iOS7.1.2 Powerd and SettingsLoadProbe executed successfully with this strict link. Keep this file if rebuilding with the same incomplete SDK; a complete compatible SDK should not need it.
